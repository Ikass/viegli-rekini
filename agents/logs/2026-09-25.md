## 2026-09-25 — Print styling: self-hosted font + document polish
Goal: Make offline PDF/print output deterministic and tidy the document layout.
What happened: Self-hosted Atkinson Hyperlegible Next (OFL, 3 weights) and wired it via `--print-font`; converted invoice meta/totals to definition lists; added `vat_rate_percentage`; tightened line-items table + margins; added `invoice-print-styling.md` spec + helper test. Follow-up tightened card padding and KPI value size.
Decision: Bundle the font instead of relying on system fonts — the prod Chromium image lacks the old stack, so metrics/diacritics drifted.
Lesson: Print/PDF rendering runs in a minimal container font set; never assume a font exists. Bundle it, set via a token, and verify the PDF embeds the weights.
