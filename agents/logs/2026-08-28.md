## 2026-08-28 — PDF generation
Goal: Phase 1 session 6 — generate a plain human-readable A4 PDF download per invoice.
What happened: Added the `ferrum_pdf` gem + initializer, an `InvoicePdf` service, and a `get :pdf` member route; the action renders the shared `invoices/print` view + `print` layout via `render_to_string`, then streams `FerrumPdf.render_pdf` as an `application/pdf` attachment. Controller test stubs `FerrumPdf.render_pdf`. 126 tests + rubocop green; real Chrome render smoke-tested (34 KB `%PDF-1.4`).
Decision: Chose `ferrum_pdf` (Chrome-rendered HTML→PDF, no Node) over Grover/Prawn — reuses the `_document` partial + print CSS with no layout drift; trade-off: requires Chromium in the prod Docker image (deferred to the deploy session).
Lesson: Minitest 6 dropped `minitest/mock`, so `Object#stub` is unavailable — stubbed `FerrumPdf.render_pdf` with a singleton override (`define_singleton_method` + `ensure remove_method`) instead.
Next: UBL 2.1 XML generation (`UblInvoiceBuilder`, PEPPOL BIS 3.0).
