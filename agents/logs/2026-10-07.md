## 2026-10-07 — UBL 2.1 XML generation (Phase 1, session 7)
Goal: Generate a downloadable UBL 2.1 XML per invoice — the machine-readable counterpart to the PDF.
What happened: Added `UblInvoiceBuilder` (`Builder::XmlMarkup`), a `get :ubl` route + `InvoicesController#ubl` (application/xml attachment). Tax grouped by mapped UNCL5305 category + rate; amounts summed in Ruby from line items; service + controller tests (well-formedness, reconciliation, escaping). Spec: `agents/docs/specs/ubl-invoice-generation.md`. Also bumped Brakeman 8.0.6→8.1.0 to clear a pre-existing `bin/ci` failure. CI green.
Decision: Target EN 16931, not PEPPOL BIS 3.0 — PEPPOL makes seller/buyer `cbc:EndpointID` + EAS schemeID mandatory (fatal PEPPOL-EN16931-R010) and the app has no endpoint data yet; add with e-adrese in Phase 6. Generate via Builder, not `.xml.erb`, because Rails only auto-escapes `.html.erb`.
Lesson: `.xml.erb` does not escape — an `&`/`<` in a client name silently malforms the XML. And SQLite stores decimal columns as floats, so sum money in Ruby (integer cents), not SQL `SUM`, when output must reconcile.
