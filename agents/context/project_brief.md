# Viegli-Rēķini — Project Brief

Viegli-Rēķini is a focused Rails 8 e-invoicing SaaS for Latvian small businesses. Multi-tenant (company accounts, multi-user, multi-location), SQLite3, Hotwire (Turbo + Stimulus), CUBE CSS, Kamal + Hetzner. Built as Reinis's primary job-search portfolio piece — code quality and architectural clarity matter as much as feature completeness, so patterns are extracted from 37signals/Basecamp reference apps and documented in `ARCHITECTURE.md` and `agents/docs/contracts/`.
